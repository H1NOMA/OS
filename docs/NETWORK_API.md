# Hiko OS — модуль «Обход блокировок» (VPN)

В Hiko встроена шина сети `OS.net`. Она даёт **переключатель обхода** в Центре
управления и маршрутизирует встроенный Браузер Hiko через твой модуль. Скачиваешь
последнюю версию модуля с GitHub, ставишь Установщиком — система сама понимает,
что это модуль обхода, и выносит кнопку включения.

## Честно про рамки

Hiko живёт в браузере, поэтому **системного VPN на весь компьютер она поднять не
может** — это способно сделать только нативное приложение с доступом к сети ОС.
Что Hiko умеет по-настоящему: пропускать запросы своего **Браузера** (и любых
приложений, которые зовут `OS.net.proxify`) через прокси твоего модуля. Для сайтов,
которые блокируются или запрещают встраивание, это часто решает вопрос. Тяжёлые
веб-приложения (YouTube, Discord) через простой прокси открываются не всегда —
это ограничение веба, а не Hiko.

**Про приватность:** когда обход включён, **весь** трафик Браузера идёт через
прокси твоего модуля — его оператор видит, какие адреса ты открываешь (а для
незашифрованных страниц — и данные). Поэтому включай только модуль и прокси,
которым доверяешь, и выключай обход, когда он не нужен.

## Как подключить

Модуль обхода — обычный `.js`-файл. Внутри один вызов:

```js
(function () {
  'use strict';

  OS.net.registerProvider({
    id: 'my-bypass',            // уникальный id
    name: 'Мой обход',          // покажется в Центре управления
    region: 'Нидерланды',       // необязательно — строка статуса
    note: 'Через свой прокси',  // необязательно

    // ГЛАВНОЕ: как перенаправить адрес через твой прокси.
    // Вызывается для каждого перехода в Браузере, когда обход включён.
    proxify(url) {
      return 'https://мой-прокси.example/?url=' + encodeURIComponent(url);
    },

    // необязательно: поднять/погасить соединение (async можно)
    async enable() { /* авторизация, прогрев туннеля и т.п. */ },
    async disable() { /* закрыть */ },
  });
})();
```

Поставь его через **Установщик** («По ссылке…» с прямым URL на `.js`, подойдут
raw.githubusercontent.com, gist, jsdelivr, unpkg) или положи в `js/apps/` при сборке.
После установки в Центре управления карточка «Обход блокировок» превратится в
переключатель, а в строке меню появится значок 🌐, когда обход включён. Модуль
хранится в `/Apps` и поднимается при каждом старте.

## Контракт `OS.net`

| Метод | Что делает |
|---|---|
| `OS.net.registerProvider(p)` | Зарегистрировать модуль обхода (см. поля выше) |
| `OS.net.providers()` | Список `{id, name, region, note}` |
| `OS.net.isOn()` | Обход включён? |
| `OS.net.setOn(bool)` | Включить/выключить (зовёт `enable`/`disable`) |
| `OS.net.toggle()` | Переключить |
| `OS.net.setProvider(id)` | Сделать модуль активным (если их несколько) |
| `OS.net.proxify(url)` | Вернуть проксированный адрес (или исходный, если обход выкл.) |

События шины: `net:providers` (список изменился) и `net:state` (`{on, provider}`).

## Своё приложение тоже может ходить через обход

```js
const res = await fetch(OS.net.proxify('https://api.example.com/data'));
```

Когда обход выключен, `proxify` возвращает адрес без изменений — код один и тот же.

## Демо-модуль

Центр управления → «Обход блокировок» → «Модуль…» → «Поставить демо». Это
готовый пример: он маршрутизирует Браузер через веб-прокси, адрес которого можно
поменять (настройка `vpnProxyBase`). Хорошая отправная точка, чтобы увидеть, как
всё устроено, и написать свой модуль под свой прокси.
