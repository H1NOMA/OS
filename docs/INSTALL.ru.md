# Hiko OS — установка рядом с Windows

Hiko — веб-система: она живёт поверх браузера, поэтому ставится за минуту,
не трогает диск, загрузчик и разделы. Честно скажу сразу: это **не** классический
dual-boot с выбором системы при включении компьютера — для этого нужно собственное
ядро. Зато в полноэкранном режиме Hiko выглядит и ощущается как отдельная система,
а переключение с Windows — обычный `Alt+Tab`.

## Установка (1 минута)

1. Скачай релиз: в репозитории — файл `dist/Hiko-1.2.0-windows.zip`
   (или просто `dist/Hiko.html` — это вся система одним файлом).
2. Распакуй в любую папку **на любом диске** — например `D:\Hiko`.
3. Запусти **`Hiko.bat`**.

Откроется отдельное окно без адресной строки и вкладок (режим приложения
Microsoft Edge — он есть в каждой Windows). Нажми `F11` — полный экран,
и на экране больше нет ничего, кроме Hiko.

## Переключение между Windows и Hiko

| Действие | Как |
|---|---|
| Перейти в Windows | `Alt+Tab` или `Win+Tab` |
| Вернуться в Hiko | `Alt+Tab` обратно |
| Свернуть Hiko | `Win+D` |
| Закрыть Hiko | `Alt+F4` (данные сохраняются сами) |

## Hiko встречает тебя при включении компьютера

1. `Win+R` → введи `shell:startup` → Enter.
2. Скопируй туда ярлык на `Hiko.bat` (ПКМ по файлу → Отправить → Ярлык, перенеси).

Теперь при входе в Windows сразу открывается Hiko — как будто загрузилась вторая система.

## Голос Ави

Открой приложение **Ави** → «Включить» фоновое прослушивание. При первом включении
браузер спросит разрешение на микрофон — разреши, и дальше просто говори:
«Хико, который час», «Ави, открой змейку». Распознавание речи лучше всего
работает в Chrome и Edge (нужен интернет — так устроен Web Speech API).

## Chrome вместо Edge

Открой `Hiko.bat` Блокнотом и замени `msedge` на `chrome` — остальное без изменений.

## Твои данные

Файлы, настройки, виджеты и установленные приложения браузер хранит с привязкой
к **расположению `Hiko.html`**. Отсюда два правила:

- Захотел перенести папку в другое место/на другой диск — сначала
  **Настройки → Данные → Экспортировать**, после переноса — **Импортировать**.
- Этот же экспорт — твоя резервная копия: один JSON-файл со всей системой.

## Обновление

Скачай новый `Hiko.html` и замени старый **в той же папке** — данные останутся
(они в браузере, а не в файле).

## Продвинутый режим (по желанию)

Максимальное погружение — киоск-режим на весь экран без единого намёка на браузер:

```
msedge --kiosk "file:///D:/Hiko/Hiko.html" --edge-kiosk-type=fullscreen
```

Выход из киоска: `Ctrl+Alt+Del` → выйти, либо `Alt+F4`.
