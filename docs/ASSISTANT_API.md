# Hiko OS — подключение голосового ассистента

В Hiko встроена шина ассистента (`OS.assistant`). По умолчанию на ней работает **Ави** —
встроенный голосовой ассистент (wake-слова «Хико»/«Хику»/«Ави», разговорный движок,
опциональный умный режим через Claude API — см. приложение «Ави»).
Твой собственный ассистент **заменяет** Ави одним вызовом — шина общая.

## Как подключить

Твой ассистент — обычный модуль Hiko: один `.js`-файл. Ставится любым способом:
- через **Установщик** (из файла или по ссылке) — попадёт в `/Apps` и будет загружаться при старте;
- либо положи в `js/apps/` и добавь `<script>` в `index.html`.

Внутри файла — один вызов:

```js
(function () {
  'use strict';

  OS.assistant.registerProvider({
    id: 'my-voice',
    name: 'Джарвис',                       // покажется в шапке панели ассистента
    hello: 'Привет! Я на связи.',          // первое сообщение в панели (опционально)

    // ГЛАВНОЕ: обработка запроса (текст из поля ввода или расшифровка голоса)
    async handle(text, ctx) {
      // ... твоя логика: свой NLU, вызов своего бэкенда, что угодно
      // Системой управляй через ctx.run(command, params) — список ниже.
      if (/приложени/.test(text)) {
        return { text: ctx.run('open-app', { name: 'змейка' }), speak: true };
      }
      return { text: 'Понял: ' + text, speak: 'Понял тебя' };
    },

    // ОПЦИОНАЛЬНО: своё распознавание речи.
    // Кнопка 🎙 в панели вызовет listen() и передаст результат в handle().
    // Если listen нет — Hiko использует системный SpeechRecognition (ru-RU).
    async listen() {
      return 'распознанный текст';
    },

    // ОПЦИОНАЛЬНО: свой синтез речи. Если нет — системный speechSynthesis.
    speak(text) { /* ... */ },
  });
})();
```

## Контракт

**`handle(text, ctx)`** → строка или `{ text, speak? }`
- `text` — ответ в чат панели;
- `speak: true` — озвучить `text` системным синтезом; `speak: 'строка'` — озвучить её.

**`ctx`:**
| Поле | Описание |
|---|---|
| `ctx.run(id, params)` | Выполнить системную команду (список ниже) |
| `ctx.commands` | Массив `{id, desc, params}` — самоописание всех команд |
| `ctx.say(text)` | Озвучить системным синтезом (ru-RU) |
| `ctx.history` | Последние 20 реплик `{role, text}` |
| `ctx.findApp(name)` | Найти приложение по человеческому названию |

## Системные команды (`ctx.run` / `OS.assistant.run`)

| Команда | Параметры | Действие |
|---|---|---|
| `open-app` | `{ name }` | Открыть приложение (умный поиск по имени) |
| `close-all` | — | Закрыть все окна |
| `show-desktop` | — | Показать рабочий стол / вернуть окна |
| `overview` | — | Обзор всех окон |
| `set-theme` | `{ theme: 'dark'\|'light' }` | Сменить тему |
| `set-wallpaper` | `{ id? }` | Обои (без id — случайные) |
| `create-note` | `{ text }` | Создать и открыть заметку |
| `search` | `{ query }` | → `{ app, files[] }` |
| `get-time` / `get-date` | — | Время / дата строкой |
| `volume` | `{ value: 0–100 }` | Громкость |
| `notify` | `{ title, body }` | Уведомление |
| `lock` / `shutdown` | — | Блокировка / выключение (с подтверждением) |
| `google` | `{ query }` | Поиск в Google (откроет Браузер) |
| `open-url` | `{ url }` | Открыть адрес в Браузере |
| `set-accent` | `{ color: '#RRGGBB' }` | Акцентный цвет системы |
| `add-widget` | `{ id: 'w-clock'\|'w-cal'\|'w-note'\|'w-mon'\|'w-weather'\|'w-photo' }` | Виджет на стол |
| `empty-trash` | — | Очистить корзину |
| `timer` | `{ minutes?, seconds?, note? }` | Таймер / напоминание |

Свои команды: `OS.assistant.registerCommand('my-cmd', { desc, run(params) {} })` —
они сразу видны в `ctx.commands`.

Полезно провайдеру: `OS.assistant.builtin(text)` — прогнать фразу через встроенные
командные интенты («открой…», «который час», «посчитай…» и т.д.). Вернёт строку-результат
или `null`, если ничего не распознано — удобно как первый уровень перед своим NLU
(именно так устроена Ави).

## Вызов ассистента

- ✦ в строке меню · `Ctrl+Alt+H` · горячий угол (Настройки → Горячие углы → «Ассистент»)
- Программно: `OS.assistant.toggle()`, `OS.assistant.ask('который час')` → `{text}`

## Заметки для голосового движка

- Всё, что нужно для работы поверх Hiko, уже есть: полный доступ к `OS.*`
  (файлы `OS.vfs`, окна `OS.wm`, настройки `OS.settings` — см. docs/APP_API.md).
- Микрофон в браузере требует разрешения пользователя; на `file://` Chrome обычно
  разрешает, но надёжнее всего — запуск через локальный сервер или Edge в режиме
  `--app` (см. docs/INSTALL.ru.md).
- Если твоему ассистенту нужен сетевой бэкенд — у источника должен быть CORS.
