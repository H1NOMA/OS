# hinomaOS

**Персональная операционная система в браузере.**
Эстетика macOS · функциональность Windows · чистый JavaScript, ноль зависимостей, ноль сборки.

![Рабочий стол](docs/screenshots/desktop.png)

## Запуск

Вариант 1 — просто открой `index.html` в браузере (Chrome/Edge/любой Chromium — рекомендуется).

Вариант 2 — локальный сервер:

```bash
npx serve .        # или: python3 -m http.server 8080
```

Все данные (файлы, настройки) хранятся локально в `localStorage` твоего браузера.

## Что внутри

### Система
- **Оконный менеджер** — перетаскивание, ресайз за 8 граней, анимации открытия/сворачивания
- **Снэп как в Windows 11** — перетащи окно к краю/углу экрана, наведи на зелёную кнопку для Snap Layouts
- **Alt + Tab** — переключатель окон, **F3** — Просмотр задач (Mission Control)
- **Aero Shake** — потряси окно, чтобы свернуть остальные
- **Dock** с магнификацией, индикаторами запущенных приложений и контекстными меню
- **Menu bar** с меню приложений, Пунктом управления, календарём и центром уведомлений
- **Spotlight** (Alt + Space) — поиск приложений, файлов и действий
- **Launchpad** — сетка всех приложений
- **Виртуальная файловая система** с корзиной и восстановлением файлов
- **Экран блокировки, загрузка, выключение** — как у взрослых
- Светлая/тёмная темы, 8 акцентных цветов, 8 фирменных обоев, Night Shift, яркость

### Приложения
| | |
|---|---|
| **Файлы** | Finder + Проводник: хлебные крошки, два вида, буфер обмена, корзина |
| **Терминал** | ls, cd, cat, echo >, neofetch и ещё дюжина команд над реальной VFS |
| **Заметки** | Текстовый редактор с предпросмотром Markdown |
| **Калькулятор** | Точная копия калькулятора macOS |
| **Браузер** | Мини-браузер со стартовой страницей и закладками |
| **Фото** | Галерея, просмотр, зум; установка обоев |
| **Paint** | Кисти, фигуры, заливка, пипетка, Undo/Redo, сохранение в PNG |
| **Сапёр** | Классика: 3 уровня, флаги, chord-клики, рекорды |
| **Диспетчер задач** | Процессы, «Снять задачу», живые графики ЦП/памяти |
| **Часы** | Мировое время, секундомер с кругами, таймер |
| **Настройки** | Темы, обои, док, пользователь, сброс системы |

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Alt + Space` | Spotlight-поиск |
| `Alt + Tab` | Переключение окон |
| `F3` | Просмотр задач |
| `Ctrl + Alt + ← / →` | Прикрепить окно влево/вправо |
| `Ctrl + Alt + ↑ / ↓` | Развернуть / свернуть окно |
| `Ctrl + W` | Закрыть окно |
| `Ctrl + Alt + L` | Заблокировать экран |
| `F2` | Переименовать файл |

## Архитектура

```
index.html
css/system.css        — дизайн-система (темы, стекло, UI-кит)
js/core/
  kernel.js           — шина событий, настройки, реестр приложений, диалоги
  vfs.js              — файловая система (localStorage)
  wallpapers.js       — генератор SVG-обоев
  wm.js               — оконный менеджер (снэп, Alt+Tab, Mission Control)
  menubar.js  dock.js  desktop.js  overlays.js  boot.js
js/apps/              — приложения (по одному файлу, см. docs/APP_API.md)
```

Хочешь своё приложение? Читай [docs/APP_API.md](docs/APP_API.md) — файл на 30 строк уже даёт окно, иконку в доке и место в Launchpad.
